# Recursos web del AMP

Este directorio queda reservado para recursos que deban sobrescribir archivos
incluidos directamente en el WAR de Alfresco Share cuando se genere un AMP.

Los recursos ordinarios de AlfDockia Community Share deben alojarse bajo
`src/main/resources/META-INF/resources`, para que el JAR los publique desde el
classpath sin modificar el WAR.

Actualmente el proyecto se distribuye como JAR y no mantiene recursos web
adicionales en este directorio.
